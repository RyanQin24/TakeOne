# Cinematic story

Start with the story arc and location changes. Find an environmental opening, a readable discovery, purposeful action and an ending earned by performance. Use live cinematic motifs only as adaptable relationships; choose exact motion from this scene and compiler evidence. Choose camera moves after deciding what the audience should notice. A hero ending can be static or a modest push; use an orbit, rise or Dolly Zoom only when it expresses this story. Do not reproduce the demonstration shot list for every brief. Preserve the user's requested pace and use silent visual beats when appropriate.
